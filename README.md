# تفاهم — Tafahum

منصة تدريب ثنائية اللغة (عربية/إنجليزية) لموظفي الجهات الحكومية على **التفاوض المبدئي وإدارة الحوار**، مبنية على مقترح بحثي يستند إلى منهج التفاوض المبدئي (Fisher & Ury) ونموذج توماس–كيلمان لأنماط إدارة الخلاف.

A bilingual (Arabic/English) training platform for government employees on **principled negotiation and dialogue management**, built on a research proposal grounded in Fisher & Ury's principled negotiation and the Thomas–Kilmann conflict-style model.

---

## التشغيل | Running

الموقع ثابت بالكامل — لا يحتاج تثبيت أو مفاتيح API:

- **الأسهل:** افتح `index.html` مباشرة في المتصفح (يعمل حتى عبر `file://`).
- **أو** شغّل خادماً محلياً:

```bash
python -m http.server 8000
# ثم افتح http://localhost:8000
```

> ملاحظة: خط Cairo يُجلب من Google Fonts؛ بدون إنترنت يعمل الموقع بالخط الاحتياطي للنظام.

The site is fully static — no install, no API keys. Either open `index.html` directly (works over `file://`), or serve it locally with `python -m http.server 8000`.

## الاختبارات | Tests

**نفس الحزمة تعمل في الطرفية وفي المتصفح** — the same suite runs in Node and in the browser:

```bash
node tests/run.mjs
```

أو افتح `test.html` في المتصفح لرؤية النتائج بصرياً. Or open `test.html` in a browser for a visual report.

تغطي الحزمة (39 اختباراً): تكافؤ مفاتيح الترجمة، اكتمال السيناريوهات ثنائيي اللغة وسلامة منطقة الاتفاق (ZOPA)، مطابقة كل شرائح الاقتراح المقترحة لنياتها في المحلل اللغوي، تقييم النصوص الجيدة مقابل السيئة، ديناميكيات محرك الطرف الآخر (الثقة، العدوان، القبول/العرض المقابل/الرفض، سقف الجولات، الحتمية)، تسرب القوالب، كاتب PDF، هيكل التقرير، والرسوم البيانية.

## رحلة المتدرب | Trainee journey

1. **مقياس الأسلوب** — 12 موقفاً على نمط توماس–كيلمان تحدد نمطك الغالب والثانوي.
2. **مكتبة المعرفة** — 8 وحدات قصيرة (المصالح مقابل المواقف، BATNA، المكسب المشترك، المعايير الموضوعية…) مع أمثلة حكومية واختبار فهم لكل وحدة.
3. **مختبر المحاكاة** — سيناريوهات حكومية جاهزة (زيادة الاعتماد، مقاول الخدمات، انتقال الكوادر، اللجنة ثلاثية الأطراف، الدوام المرن، معاملة مواطن) **أو سيناريو خاص تبنيه بنفسك**؛ تحاور طرفاً آخر قائماً على قواعد يتفاعل مع أسئلتك وعروضك ونبرتك، مع مدرب مباشر يقترح صياغات بديلة.
4. **التقرير** — نتيجة إجمالية (50% سلوك + 50% نتيجة الاتفاق)، المحكّات السبعة، مهارات الحوار الأربع، نقاط القوة والضعف **مقسّمة بين مهارات الحوار ومهارات التفاوض**، مسار الخبير («كيف كان يمكن أن تسير الجلسة»)، تحليل SWOT للموضوع، وملاحظات إرشادية لإصلاح الضعف — مع تصدير PDF عربي/إنجليزي.
5. **لوحة الأداء** — تتبع الجلسات والنتائج والأسئلة السابقة.

## البنية | Architecture

```
index.html          غلاف SPA (شريط علوي، توجيه بالهاش، تذييل)
assets/css/         نظام التصميم (RTL أولاً، خصائص منطقية، طباعة)
assets/js/
  core.js            أدوات مشتركة (تخزين محلي، RNG مبذور، عناصر DOM)
  i18n.js            حزمتا الترجمة AR/EN + تسميات المحكّات
  scenarios.js       مكتبة السيناريوهات + منشئ السيناريو الخاص
  analyzer.js        محلل الرسائل (نواة لغوية عربية/إنجليزية + أرقام بوحداتها)
  evaluator.js       التقييم: المحكّات السبعة + مهارات الحوار الأربع + النتيجة
  engine.js          عقل الطرف الآخر (ثقة، صلابة، نقاط تحفظ، شخصيات)
  coach.js           المدرب المباشر + شرائح الاقتراح
  diagnostic.js      مقياس الأسلوب (توماس–كيلمان)
  knowledge.js       وحدات التعلّم
  charts.js          رسوم SVG (رادار، أعمدة، خطوط)
  pdfwriter.js       كاتب PDF بدون أي مكتبة خارجية (DCTDecode)
  report.js          تجميع التقرير + HTML + تصدير PDF
  app.js             الواجهة والتوجيه والجلسات
tests/               حزمة الاختبارات (Node + متصفح)
```

كل الوحدات بصيغة UMD: تعمل كنصوص كلاسيكية في المتصفح **و** عبر `require` في Node للاختبارات — لا أدوات بناء ولا `npm install`.

- **محرك الطرف الآخر** حتمي (بذرة عشوائية لكل جلسة)، بلا أي نداءات شبكية.
- **الذكاء قائم على قواعد**: نوايا لغوية، أرقام مرتبطة بأبعاد السيناريو عبر وحداتها (٪/شهر/يوم/أسبوع/كادر)، ديناميكيات ثقة وصلابة، نقاط تحفظ لكل بعد، وشخصيات (حارس/براغماتي/مضغوط/متشارك).
- **PDF** يُبنى يدوياً: صفحات A4 كصور JPEG مدمجة عبر XObjects — بدون تبعيات، مع تراجع إلى طباعة المتصفح.
- **البيانات** (الجلسات، التشخيص، التقدم) محفوظة محلياً في متصفحك فقط.
